# 교육채널 오름 · 뇌기능검사와 학습 상담

백주경 교육학 박사의 학습 상담과 뇌기능검사를 안내하는 정적 랜딩페이지입니다. 학부모의 학습 고민, 한 줄 기록 예시, 뇌파 측정과 결과 해석의 범위, 상담 문의를 소개합니다.

- 공개 주소: https://orumedu.github.io/brain-function-assessment/
- 문의: 페이지의 카카오톡 상담 버튼
- 버전 기록: [변경 이력](CHANGELOG.md)
- 사진: [이미지 생성 기록](docs/image-prompts.md)

## 파일과 미리보기

- `index.html`에 페이지의 내용과 링크를 담았습니다.
- `styles.css`가 화면 크기에 따른 레이아웃을 정합니다.
- `assets/`의 사진 5장은 한국 드라마풍으로 생성한 예시 장면입니다.

`index.html`을 브라우저로 열면 미리 볼 수 있습니다. 별도의 빌드와 실행 환경이 필요한 구성 요소는 없습니다.

## 공개와 버전 관리

GitHub Pages에서 `main` 브랜치의 루트 폴더를 공개 경로로 사용합니다. 수정 시 [변경 이력](CHANGELOG.md)에 변경 내용과 날짜를 적고, 검토한 시점의 코드를 버전 태그로 남깁니다. 상담은 외부 채널로 안내하며 이 저장소에는 공개용 자료만 보관합니다.
